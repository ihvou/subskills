# Contributing to Subskills

Thanks for helping out. A few notes:

- **Bugs and ideas:** open an issue. For a bug, say which page or screen, what you expected and what happened instead.
- **Pull requests:** keep each one to a single change. Run `npm run lint`, `npm run typecheck` and `npm run test` before opening it, and `npm run test:e2e:web` if you changed the website.
- **Data:** the catalog is built by a separate pipeline and isn't in this repository. With no Supabase variables set, the website runs on a small built-in demo catalog, which is enough for most changes.
- **License:** by contributing, you agree that your contribution is licensed under the [AGPL-3.0](LICENSE), like the rest of the code.
